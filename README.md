# HeartDiseasePredictor
Uses a Random Forest model to predict whether a patient has heart disease based on factors such as sex, age, cholesterol, max heart rate, etc. Trained on the UCI Heart Disease dataset (918 patients from four hospitals). Power BI dashboard for a separate, smaller dataset with interactive visuals of disease rate by gender and age.

Evaluated Baseline model + Fine tuned via Grid Search CV

- Baseline Accuracy: 83.70%
- Baseline Dice/F1: 85.44%
- Baseline ROC-AUC: 92.53%
- Fine-tuned Accuracy: 83.70%
- Fine-tuned Dice/F1: 85.58%
- Fine-tuned ROC-AUC: 92.43%

FineTuning did not meaningfully improve on the baseline.
